# Planning — R1 (project 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three planning aids from the data the add-on already has: a 30-day cash forecast "if nothing comes in" (a Home tile that opens what it counted in place, a weekly check-in line in Full detail, `/forecast` in Telegram, and a daily-report warning when cash may run short within 14 days), a month-in-review section on the monthly report in Full detail, and unread state on the Reports tab (a count on the tab and each report's tab, "New" on unseen editions, opening a report's tab marks it seen on every device).

**Architecture:** Four pure shared modules: `shared/forecast.ts` (the arithmetic: which roster entries are bills, every charge of each inside the window, the daily balance series, its low point and first short day, Wealthfolio's "today"), `shared/cash-forecast.ts` (the `cash_forecast` secret — strict ok / absent / corrupt parse, the companion-version gate, the stale rule — and every line the app and Telegram show), `shared/forecast-inputs.ts` (cash today from the bank balances of mapped CASH accounts, the history months, daily spending less the bills' own past charges, and the assembled forecast) and `shared/month-review.ts` (the review's data and its Telegram section), plus `shared/reports-seen.ts` (the `reports_seen` document and unread counting). The companion gathers the forecast's reads on their own (`companion/src/cash-forecast-facts.ts`) and publishes `cash_forecast` after each sync, last, beside the audit snapshot; the weekly check-in, the daily report and `/forecast` read that published value. The monthly composer adds the review in Full detail. The add-on reads the forecast corrupt-aware (`SecretsStore.getCashForecast`) and renders it on Home (`src/components/ForecastViews.tsx`); the page holds the inbox (`src/hooks/useReportsInbox.ts`) so the tab bar and the Reports tab's sub-tabs agree.

**Tech Stack:** TypeScript, React (add-on), vitest (root project: jsdom, `src/` + `shared/`; companion project: node, `companion/src/`), Telegram Bot API (legacy `Markdown`), Wealthfolio REST and read-only SQLite (companion), add-on SDK 3.6.2 on Wealthfolio 3.8–3.10.

**Spec:** `docs/superpowers/specs/2026-10-14-planning-design.md` (commit 44c849e on `feat/planning`, off main ece1902). Designed overnight and **not yet reviewed by Nick**: this plan follows it faithfully, rulings N1–N6, with the coordinator's rulings Q1–Q6 folded in. It ships as an open PR.

**Verified facts this plan builds on (Q1):**
- **(a) Cash today.** `account_balances` is an add-on secret the SYNC writes at the end of every run (`await store.setAccountBalances(accountBalances)`, `shared/sync-core.ts:3972`), keyed by **SimpleFin** account id, one entry per MAPPED account in the feed (the loop skips unmapped ones, `:2393`): `{ balance: dollars | null, currency, date: Unix seconds (SimpleFin's balance-date), drift, measured }` (`:2953-2962`). A SimpleFin account maps to a Wealthfolio account through `account_mapping` (SimpleFin id → Wealthfolio id). Each Wealthfolio account's type and archived/hidden state come from `GET /accounts` (`WealthfolioClient.getAccounts`, `companion/src/wealthfolio.ts:101`; the SDK's `Account` carries `isActive` and `isArchived`, `node_modules/@wealthfolio/addon-sdk/dist/src/data-types.d.ts:104-105`); the client's return type is widened in Task 4 to name `name` and `isActive`. The companion already sums balances by type for the runway (`readRunwayMonths`, `companion/src/pool-report.ts:97-125`). So cash = the `account_balances` dollars of mapped accounts whose Wealthfolio account is `CASH`, neither `isArchived` nor `isActive === false`; cards, investment accounts and unmapped accounts are left out (`cashToday`, Task 3). A counted account with no numeric balance, or no date, is named in `missing` and left out; a balance whose day is more than 3 days before the forecast is counted and shown "· Balance from Oct 9".
- **(b) Bills.** `buildRoster` (`shared/subscription-roster.ts:204`) builds `subscriptions`, `bills`, `maybes` and `hidden` from the cube's `subscriptions`/`merchants`/`subscriptionLinks` and the subscription document; the companion builds it the same way for every Telegram surface (`readSubscriptionRoster`, `companion/src/subscription-data.ts:24-35`; `readRosterFor`, `companion/src/index.ts:1636`), which Task 4 follows. Counted: `subscriptions` and `bills` with a `nextDate` (`nextDate` is null once overdue and for watched names, `:104`); not `maybes`, not `hidden` (`buildRoster` keeps hidden ones out of both lists). A LATE entry (date passed inside `LATE_GRACE_DAYS` = 7, not charged yet, `:149,162-168`) is subtracted today. Later occurrences come from `addPeriod(nextDate, cadence, n)` (`:57`), counted from the next date so a 31st stays the 31st. **The roster can't tell which account an entry charges:** `DetectedSubscription` has no account (`shared/subscriptions.ts:36-58`) and the cube's merchant rows carry none (`getNativeMerchantRows` selects month, date, notes, amount, `companion/src/sqlite-native.ts:1461-1493`), so a card-charged bill is subtracted from cash too (pessimistic; its past charges leave the daily figure, so it is never counted twice). **Card payments can reach the roster:** a linked one never does (the uncategorized half of the merchant rows requires `source_group_id = ''`, `:1488`, and the categorized half drops transfer-named categories, `REPORT_COUNTS_CATEGORY`, `:186`), but one that never linked expires into a WITHDRAWAL (`expiredTransferLegType`, `shared/sync-core.ts:1314`) and is then a merchant row like any other. `forecastBills` leaves out an entry whose key, bank name or display name matches the sync's own `CASH_CARD_PAYMENT_KEYWORDS` (`shared/mapper.ts:18`).
- **(c) Daily spend.** `monthEndForecast` (`shared/projection.ts:38`) averages the previous three full months' outflow per calendar day (`previousThreeFullMonths`, `:62`). The headline the ruling names is the report's "Spent this month" — `monthlySpendTotals` (`shared/report-cube.ts:170`), the Budget tab's default headline stat (`shared/report-data.ts:370,411`): categorized plus uncategorized, every mapped account, cards included (the `CREDIT_CARD` arm of `SPENDING_SIGN`, `companion/src/sqlite-native.ts:208-221`), transfer-named categories (`:186`) and dismissed rows left out. So daily spending = (the history months' `monthlySpendTotals` − the counted bills' charges in those months) ÷ their calendar days, never below 0. The bills' past charges are summed from the same merchant rows the detector reads, grouped by the detector's own key (`categoryRulePattern(descriptionFromComment(notes)) || …`, `shared/subscriptions.ts:102`, `companion/src/report-cube-build.ts:228-232`). History months: up to three full months before today's month; the month history starts in is partial (the first import rarely starts on the 1st) unless it is the cube's first month (`historyMonths`, Task 3). None: no forecast, "Not enough history yet — the forecast needs one full month of spending."

**Deviations from the spec (decided, do not "fix"):**
- **No weekly bills exist.** `Cadence` is `'monthly' | 'yearly'` (`shared/subscription-roster.ts:21`) and the detector is monthly-only. `expandBills` repeats any cadence through `addPeriod`; Review Focus's "repeats inside the window" is pinned with a monthly bill (twice in a 30-day window, and inside February) and a yearly one (once).
- **The window is today plus 30 days: 31 points.** Day 0 is the bank's balance less any bill due today; each later day costs one day of spending. Bills are subtracted on their dates through the 30th day — the spec's "$1,240 left on Nov 13" is a forecast made Oct 14.
- **Today is Wealthfolio's day** (`zonedDay`, Task 1), and the history months are the cube's months before it. `zonedMonthBounds` (`shared/audit-headline.ts:386`) gives a month's RFC 3339 instants for a REST query; the forecast needs a calendar day, so `zonedDay` uses the same zone handling and the same fallback (null or an unknown zone → the process's own).
- **`cash_forecast` adds `missing`** (CASH accounts left out for want of a dated balance) to the ruling's shape, so the app can name them.
- **Copy the spec left open:** "based on 2 months" / "based on 1 month" replaces "(your last N months)" while N < 3; the 🔮 follows the report glyph style like every report's header glyph (clean, the default, drops it) while ⚠️ always shows, like 🚨; the weekly line when cash runs short is "⚠️ Next 30 days: cash may run short around Nov 3 if nothing comes in."
- **The weekly line and the daily warning use only a fresh forecast** (2 days); `/forecast` shows an old one with "⚠️ This forecast is from … — the companion hasn't synced since." The warning shows for a short date from today through today + 14, never for a day already past.
- **No cash account, no balance or no history is checked before the spending history is read,** so a forecast that cannot exist says why rather than naming a later read.
- **"New" subscriptions** are entries whose whole charge history is known, whose first charge is in the reviewed month or the one before, and that charged in the reviewed month: a subscription reaches the roster only at its second charge, so one that starts in a month is rarely known by its end, and "first charge in the month" would almost never fire. Copy: "New: Netflix $15.49/mo (since Aug 5)". The residuals are in follow-ups §15.
- **The review is also in the Reports tab's live monthly edition** ("October so far"), in Full detail — the same composer.
- **Unread counts sent editions only.** The live edition is recomposed every sync and is never "new". A kind the document has no time for counts every sent edition; on a first run (or a corrupt document) everything is seen and each kind's newest edition is written as the baseline once.
- **Opening a sub-tab keeps its "New" markers for that visit;** the counts drop only when the write lands.
- **A hand-added bill not linked to a merchant** keeps its past charges in daily spending: nothing can tell them apart (pessimistic).

**Task order:** the forecast's arithmetic (1), the published value and its words (2), its inputs (3); the companion's reads and publish after each sync (4) and the Telegram surfaces (5); the month in review (6) and the monthly report (7); unread counting and the store (8); the app's tile (9) and the inbox (10); docs, the forced-date run and every gate (11).

### Task 1: The forecast's arithmetic — bills on their dates, the low point, the first short day

`shared/forecast.ts` (spec A; N1–N2; Q1b). /**
```ts
 * shared/forecast.ts
 *
 * The 30-day cash forecast's arithmetic (project 5 R1, spec A; rulings N1–N2):
 * cash today, minus each known bill on its date, minus a typical day of other
 * spending for every day after today. It assumes NO income — nothing in the
 * add-on detects paychecks — so what it says is "if nothing comes in", never a
 * promise. Pure: shared/forecast-inputs.ts gathers what goes in, and
 * shared/cash-forecast.ts is the published result and its words.
 *
 * Dates are YYYY-MM-DD strings, computed in UTC like the roster's, so a host's
 * zone can never shift a day; `today` is the caller's (Wealthfolio's) day.
 */
import { CASH_CARD_PAYMENT_KEYWORDS } from './mapper.js';
import { addDaysIso, addPeriod, localIsoDay, type Roster, type RosterEntry } from './subscription-roster.js';

/** How far the forecast looks: today, then 30 more days. */
export const FORECAST_DAYS = 30;

/** One bill charge inside the window. `name` is RAW bank or user text. */
export interface ForecastCharge { name: string; date: string; cents: number }

export interface CashProjection {
  /** The balance at the end of each day, today first: `days + 1` points. */
  series: Array<{ date: string; cents: number }>;
  /** The lowest balance, and the FIRST day it is reached. */
  lowCents: number;
  lowDate: string;
  /** The first day the balance is below $0, or null. */
  shortDate: string | null;
}

/**
 * The roster entries the forecast subtracts: subscriptions and bills with a
 * next date. Not maybes (unconfirmed), not hidden (`buildRoster` keeps them
 * out of both lists), not overdue or watched (`nextDate` is null: no date is
 * known). Not a card payment either: those are transfers, and card spending
 * reaches cash only through them, which the daily spending already stands in
 * for. A payment Wealthfolio linked is never a merchant row; one that never
 * linked (expired into a withdrawal) can be detected, so an entry whose bank
 * or given name reads like one — the sync's own CASH_CARD_PAYMENT_KEYWORDS —
 * is left out.
 */
export function forecastBills(roster: Pick<Roster, 'subscriptions' | 'bills'>): RosterEntry[] {
  return [...roster.subscriptions, ...roster.bills]
    .filter((e) => e.nextDate !== null && !isCardPayment(e));
}

function isCardPayment(e: RosterEntry): boolean {
  return [e.key, e.bankName ?? '', e.displayName].some((text) => CASH_CARD_PAYMENT_KEYWORDS.test(text));
}

/**
 * Every charge of `entries` from `today` through `today + days`, date order.
 * Each entry's later dates are `addPeriod(nextDate, cadence, n)` — counted
 * from its next date, so a 31st stays the 31st wherever a month has one
 * (Oct 31 → Nov 30 → Dec 31). A LATE entry (its date passed inside the
 * roster's grace, not charged yet) has not left the account: it is subtracted
 * today. An entry with no price subtracts nothing.
 */
export function expandBills(entries: readonly RosterEntry[], today: string, days: number): ForecastCharge[] {
  const end = addDaysIso(today, days);
  const out: ForecastCharge[] = [];
  for (const e of entries) {
    if (e.nextDate === null || !(e.cents > 0)) continue;
    for (let n = 0; ; n += 1) {
      const due = addPeriod(e.nextDate, e.cadence, n);
      if (due > end) break;
      if (due < today) {
        if (n === 0) out.push({ name: e.displayName, date: today, cents: e.cents });
        continue;
      }
      out.push({ name: e.displayName, date: due, cents: e.cents });
    }
  }
  return out.sort((a, b) => a.date.localeCompare(b.date) || a.name.localeCompare(b.name) || b.cents - a.cents);
}

/**
 * The balance at the end of each day: `cashCents` today, less every bill
 * dated on or before that day, less `dailySpendCents` for each day after
 * today (today's spending is already in the bank's balance). A negative daily
 * figure counts as none. With no income the series never rises, so the low
 * point is where it ends — or the day of the last bill when nothing else is
 * spent.
 */
export function forecastCash(input: {
  cashCents: number; today: string; bills: readonly ForecastCharge[]; dailySpendCents: number; days: number;
}): CashProjection {
  const { cashCents, today, bills, days } = input;
  const daily = Math.max(0, Math.round(input.dailySpendCents));
  const series: CashProjection['series'] = [];
  let lowCents = Number.POSITIVE_INFINITY;
  let lowDate = today;
  let shortDate: string | null = null;
  for (let i = 0; i <= days; i += 1) {
    const date = addDaysIso(today, i);
    const billed = bills.reduce((sum, b) => (b.date <= date ? sum + b.cents : sum), 0);
    const cents = cashCents - daily * i - billed;
    series.push({ date, cents });
    if (cents < lowCents) {
      lowCents = cents;
      lowDate = date;
    }
    if (shortDate === null && cents < 0) shortDate = date;
  }
  return { series, lowCents, lowDate, shortDate };
}

/**
 * The calendar day `now` falls on in `timeZone` — Wealthfolio's own setting,
 * the zone its month boundaries use. Null, or a zone the runtime does not
 * know, uses the process's own zone (the companion's `TZ`), the same fallback
 * as `zonedMonthBounds` in shared/audit-headline.ts.
 */
export function zonedDay(now: Date, timeZone: string | null): string {
  if (timeZone) {
    try {
      const parts = new Intl.DateTimeFormat('en-US', {
        timeZone, year: 'numeric', month: '2-digit', day: '2-digit',
      }).formatToParts(now);
      const p = Object.fromEntries(parts.map((x) => [x.type, x.value]));
      return `${p.year}-${p.month}-${p.day}`;
    } catch {
      /* an unknown zone: the process's own, below */
    }
  }
  return localIsoDay(now);
}
```

```ts
const isObject = (x: unknown): x is Record<string, any> => !!x && typeof x === 'object' && !Array.isArray(x);
const isInt = (x: unknown): x is number => Number.isInteger(x);
const isDay = (x: unknown): x is string =>
  typeof x === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(x) && !Number.isNaN(Date.parse(`${x}T00:00:00Z`));

/** The stored secret: absent when there is none, corrupt when it is not
 *  exactly a forecast this version can show — every field the views read —
 *  else the forecast. */
export function parseCashForecast(raw: string | null | undefined): CashForecastRead {
  if (raw === null || raw === undefined || raw === '') return { kind: 'absent' };
  const corrupt = { kind: 'corrupt' } as const;
  let v: any;
  try {
    v = JSON.parse(raw);
  } catch {
    return corrupt;
  }
  if (!isObject(v) || v.v !== 1 || typeof v.at !== 'string' || Number.isNaN(Date.parse(v.at))) return corrupt;
  if (v.ok === false) {
    return typeof v.reason === 'string' && v.reason.trim() !== '' ? { kind: 'ok', forecast: v as CashForecastFailed } : corrupt;
  }
  if (v.ok !== true) return corrupt;
  if (!isInt(v.cashCents) || !isInt(v.lowCents) || !isInt(v.dailySpendCents)) return corrupt;
  if (!isDay(v.lowDate) || (v.shortDate !== undefined && !isDay(v.shortDate))) return corrupt;
  if (!isInt(v.days) || v.days < 1 || !isInt(v.basedOnMonths) || v.basedOnMonths < 1 || v.basedOnMonths > 3) return corrupt;
  if (!Array.isArray(v.accounts) || !v.accounts.every((a: unknown) => isObject(a) && typeof a.name === 'string' && isInt(a.cents) && isDay(a.asOf))) return corrupt;
  if (!Array.isArray(v.bills) || !v.bills.every((b: unknown) => isObject(b) && typeof b.name === 'string' && isInt(b.cents) && isDay(b.date))) return corrupt;
  if (v.missing !== undefined && !(Array.isArray(v.missing) && v.missing.every((m: unknown) => typeof m === 'string'))) return corrupt;
  return { kind: 'ok', forecast: v as CashForecastOk };
}

export type ForecastView =
  | { state: 'hidden' }
  | { state: 'update' | 'not-yet' | 'corrupt' | 'failed'; line: string }
  | { state: 'ok'; forecast: CashForecastOk; stale: boolean; status: string };

/**
 * What the Home tile shows. Hidden before the read lands and for an add-on-only
 * install (nothing published, no companion); "Update the companion to see
 * this" while the companion predates CASH_FORECAST_SINCE — the same gate as
 * the change log's Undo; otherwise the forecast, the reason there is none, or
 * that it could not be read. A stale forecast still shows, saying so.
 */
export function cashForecastView(read: CashForecastRead | null, companionVersion: string | null, now: Date): ForecastView {
  if (read === null) return { state: 'hidden' };
  if (read.kind === 'corrupt') return { state: 'corrupt', line: FORECAST_CORRUPT };
  if (read.kind === 'absent') {
    if (!companionVersion) return { state: 'hidden' };
    return companionPublishesForecast(companionVersion)
      ? { state: 'not-yet', line: FORECAST_NOT_YET }
      : { state: 'update', line: FORECAST_UPDATE_COMPANION };
  }
  const f = read.forecast;
  if (!f.ok) return { state: 'failed', line: f.reason };
  if (forecastIsStale(f, now)) return { state: 'ok', forecast: f, stale: true, status: forecastStaleLine(f) };
  const at = new Date(f.at);
  const sameDay = at.toDateString() === now.toDateString();
  return { state: 'ok', forecast: f, stale: false, status: `As of the ${sameDay ? '' : `${localDay(at)}, `}${localClock(at)} sync.` };
}

/** The daily report's warning, Brief and Full alike: only when a fresh
 *  forecast runs short within FORECAST_WARN_DAYS of `today`. */

  const short = read.forecast.shortDate;
  if (!short) return null;
  const days = daysBetween(today, short);
  if (days < 0 || days > FORECAST_WARN_DAYS) return null;
  return `⚠️ Cash may run short around ${shortDate(short)} if nothing comes in.`;

  const f = read.forecast;
  if (!f.ok) return `No forecast right now: ${escapeMarkdown(f.reason)}`;
  const lines = [forecastTelegramLine(f, style), '', escapeMarkdown(forecastCashLine(f))];
  for (const a of f.accounts) lines.push(escapeMarkdown(forecastAccountLine(a, f)));
  for (const name of f.missing ?? []) lines.push(escapeMarkdown(forecastMissingLine(name)));
  lines.push('', `*${FORECAST_BILLS_LABEL}*`);
  if (f.bills.length === 0) lines.push(FORECAST_NO_BILLS);
  for (const b of f.bills.slice(0, FORECAST_REPLY_BILLS)) lines.push(escapeMarkdown(forecastBillLine(b)));
  const more = f.bills.length - FORECAST_REPLY_BILLS;
  if (more > 0) lines.push(`…and ${more} more`);
  lines.push('', forecastAssumption(f));
  if (forecastIsStale(f, now)) lines.push('', `⚠️ ${forecastStaleLine(f)}`);
  return lines.join('\n');
}
```

```ts
/**
 * shared/forecast-inputs.ts
 *
 * What goes into the 30-day forecast (project 5 R1, spec A; rulings N1–N2),
 * pure — the companion does the reads (companion/src/cash-forecast-facts.ts):
 *
 *  - Cash today: the bank balances (`account_balances`, dollars, keyed by
 *    SimpleFin id) of the mapped accounts whose Wealthfolio account is CASH
 *    and neither archived nor hidden. Cards, investment accounts and unmapped
 *    accounts are left out. A counted account the bank sent no dated balance
 *    for is left out BY NAME, never silently.
 *  - The bills: the roster's subscriptions and bills with a date
 *    (forecastBills in shared/forecast.ts).
 *  - Daily spending: the report's spending — the cube's `monthlySpendTotals`,
 *    the Budget tab's "Spent this month": every category, every mapped
 *    account, cards included, transfer-named categories and dismissed rows
 *    left out exactly as that headline leaves them out — over the last full
 *    months (up to three), less those months' charges of the counted bills so
 *    a bill is never subtracted twice, per calendar day, never below $0.
 */
import { failedForecast, type CashForecast, type ForecastAccount } from './cash-forecast.js';

/** A Wealthfolio account as `GET /accounts` returns it. */
export interface WealthfolioAccountLike {
  id: string;
  name?: string;
  accountType?: string;
  isArchived?: boolean;
  isActive?: boolean;
}

export interface CashTodayInput {
  /** account_mapping: SimpleFin id → Wealthfolio id. */
  mapping: Record<string, string>;
  /** account_balances: the sync's snapshot, `balance` in dollars, `date` in Unix seconds. */
  balances: Record<string, { balance?: unknown; date?: unknown } | null | undefined>;
  /** account_names: SimpleFin id → the bank's name for it. */
  names: Record<string, string>;
  accounts: readonly WealthfolioAccountLike[];
}

export interface CashToday {
  cashCents: number;
  /** Counted, by name. */
  accounts: ForecastAccount[];
  /** CASH accounts with no dated balance from the bank, by name. */
  missing: string[];
}

const own = (rec: object, key: string): boolean => Object.prototype.hasOwnProperty.call(rec, key);

export function cashToday(input: CashTodayInput): CashToday {
  const byId = new Map(input.accounts.map((a) => [a.id, a] as const));
  const accounts: ForecastAccount[] = [];
  const missing: string[] = [];
  for (const [sfinId, wfId] of Object.entries(input.mapping)) {
    const account = wfId ? byId.get(wfId) : undefined;
    if (!account || (account.accountType ?? '').trim().toUpperCase() !== 'CASH') continue;
    if (account.isArchived === true || account.isActive === false) continue;
    const name = (own(input.names, sfinId) && input.names[sfinId]) || account.name || sfinId;
    const b = own(input.balances, sfinId) ? input.balances[sfinId] : undefined;
    const balance = b && typeof b.balance === 'number' && Number.isFinite(b.balance) ? b.balance : null;
    const date = b && typeof b.date === 'number' && Number.isFinite(b.date) ? b.date : null;
    if (balance === null || date === null) {
      missing.push(name);
      continue;
    }
    accounts.push({ name, cents: Math.round(balance * 100), asOf: new Date(date * 1000).toISOString().slice(0, 10) });
  }
  accounts.sort((a, b) => a.name.localeCompare(b.name));
  missing.sort((a, b) => a.localeCompare(b));
  return { cashCents: accounts.reduce((sum, a) => sum + a.cents, 0), accounts, missing };
}

const pad2 = (n: number) => String(n).padStart(2, '0');
const shift = (month: string, n: number): string => {
  const [y, m] = month.split('-').map(Number);
  const total = y * 12 + (m - 1) + n;
  return `${Math.floor(total / 12)}-${pad2((total % 12) + 1)}`;
};
const daysInMonth = (month: string): number => {
  const [y, m] = month.split('-').map(Number);
  return new Date(Date.UTC(y, m, 0)).getUTCDate();
};

/**
 * The full months (up to three, oldest first) before `currentMonth` — today's
 * month in Wealthfolio's zone — that the cube has history for. The month the
 * history starts in is partial (the first import rarely starts on the 1st)
 * unless it is the cube's first month, whose history the cube trimmed.
 * Empty when there is no full month yet.
 */
export function historyMonths(cube: ReportCube, currentMonth: string): string[] {
  const spend = monthlySpendTotals(cube);
  const income = monthlyIncomeTotals(cube);
  const first = cube.months.findIndex((_, i) => spend[i] !== 0 || income[i] !== 0);
  if (first === -1) return [];
  const firstFull = first === 0 ? 0 : first + 1;
  const out: string[] = [];
  for (let back = 1; back <= 3; back += 1) {
    const month = shift(currentMonth, -back);
    const i = cube.months.indexOf(month);
    if (i < firstFull) break;
    out.unshift(month);
  }
  return out;
}

/** The date range `getNativeMerchantRows` takes for `months` (contiguous, oldest first). */
export function historyWindow(months: readonly string[]): { startInclusive: string; endExclusive: string } {
  return { startInclusive: `${months[0]}-01`, endExclusive: `${shift(months[months.length - 1], 1)}-01` };
}

/** One spending row as `getNativeMerchantRows` reads it: the stored note verbatim, dollars. */
export interface MerchantRow { month: string; notes: string; amount: number }

/** The name the subscription detector groups a row under (shared/subscriptions.ts):
 *  the note's description, trimmed to its rule pattern. '' for a row with none. */
export function detectorKey(notes: string): string {
  const name = descriptionFromComment(notes);
  return name ? categoryRulePattern(name) || name : '';
}

/** The detector keys whose charges are the counted bills': a detected entry's
 *  own key, a hand-added entry's linked merchant. A hand-added entry with no
 *  link has no charges anyone can tell apart, so they stay in daily spending. */
export function billKeys(entries: readonly RosterEntry[], manual: readonly ManualSubscription[]): Set<string> {
  const merchantOf = new Map(manual.map((m) => [manualKey(m.id), m.merchant] as const));
  const keys = new Set<string>();
  for (const e of entries) {
    if (e.source === 'detected') keys.add(e.key);
    else if (e.source === 'manual') {
      const merchant = merchantOf.get(e.key);
      if (merchant) keys.add(merchant);
    }
  }
  return keys;
}

/** What the counted bills charged in `months` (refunds subtract), in cents. */
export function billChargesCents(rows: readonly MerchantRow[], keys: ReadonlySet<string>, months: readonly string[]): number {
  if (keys.size === 0) return 0;
  const wanted = new Set(months);
  let cents = 0;
  for (const r of rows) {
    if (!wanted.has(r.month)) continue;
    const key = detectorKey(r.notes);
    if (key && keys.has(key)) cents += Math.round(r.amount * 100);
  }
  return cents;
}

/** (The months' spending − the bills' charges) ÷ the months' calendar days, never below 0. */
export function dailySpendCents(cube: ReportCube, months: readonly string[], billCents: number): number {
  if (months.length === 0) return 0;
  const spend = monthlySpendTotals(cube);
  let total = 0;
  let days = 0;
  for (const month of months) {
    const i = cube.months.indexOf(month);
    if (i >= 0) total += spend[i];
    days += daysInMonth(month);
  }
  return Math.max(0, Math.round((total - billCents) / days));
}

export interface ForecastBuildInput {
  now: Date;
  /** Today in Wealthfolio's zone (zonedDay). */
  today: string;
  cash: CashToday;
  roster: Roster;
  /** The subscription document's hand-added entries, for their linked merchants. */
  manual: readonly ManualSubscription[];
  cube: ReportCube;
  /** historyMonths(cube, today's month). */
  months: readonly string[];
  /** getNativeMerchantRows over historyWindow(months). */
  merchantRows: readonly MerchantRow[];
  days?: number;
}

/** The `cash_forecast` value: the forecast, or why there is none. */
export function buildCashForecast(input: ForecastBuildInput): CashForecast {
  const { now, today, cash, cube, months } = input;
  const days = input.days ?? FORECAST_DAYS;
  if (cash.accounts.length === 0) return failedForecast(cash.missing.length > 0 ? 'noBalance' : 'noCash', now);
  if (months.length === 0) return failedForecast('noHistory', now);
  const entries = forecastBills(input.roster);
  const billCents = billChargesCents(input.merchantRows, billKeys(entries, input.manual), months);
  const daily = dailySpendCents(cube, months, billCents);
  const bills = expandBills(entries, today, days);
  const p = forecastCash({ cashCents: cash.cashCents, today, bills, dailySpendCents: daily, days });
  return {
    v: 1,
    at: now.toISOString(),
    ok: true,
    cashCents: cash.cashCents,
    lowCents: p.lowCents,
    lowDate: p.lowDate,
    ...(p.shortDate ? { shortDate: p.shortDate } : {}),
    days,
    basedOnMonths: months.length,
    dailySpendCents: daily,
    accounts: cash.accounts,
    bills,
    ...(cash.missing.length > 0 ? { missing: cash.missing } : {}),
  };
}
```

```ts
/**
 * companion/src/cash-forecast-facts.ts
 *
 * Gathers the 30-day cash forecast's reads and publishes `cash_forecast`
 * after each sync (project 5 R1, spec A). The arithmetic and the decisions
 * are shared/forecast.ts and shared/forecast-inputs.ts; this file only reads,
 * each read on its own:
 *
 *  - account_mapping, account_balances and account_names: add-on secrets;
 *  - each account's type and archived/hidden state: `GET /accounts`;
 *  - the report cube (spending history and the detected subscriptions) and
 *    the subscription document: add-on secrets, built into the roster exactly
 *    as every other surface builds it (subscription-data.ts's shape);
 *  - the bills' past charges: the merchant rows (strict — a database that
 *    cannot be read is a reason, never "no charges");
 *  - Wealthfolio's timezone: its settings, null when unreadable (the
 *    process's own zone then).
 *
 * A read that fails becomes `{ ok: false, reason }` — never a number. When
 * Wealthfolio cannot be reached at all nothing is written, so the previous
 * forecast stays.
 */
import { CASH_FORECAST_SECRET_KEY, failedForecast, type CashForecast } from '../../shared/cash-forecast.js';
import { zonedDay } from '../../shared/forecast.js';
import {
  buildCashForecast, cashToday, historyMonths, historyWindow, type MerchantRow, type WealthfolioAccountLike,

import type { WealthfolioClient } from './wealthfolio.js';

const ADDON_ID = 'simplefin-sync';

/** Everything the forecast reads, so a test can fake each in its real shape. */
export interface ForecastReaders {
  /** One add-on secret; rejects when Wealthfolio cannot be reached. */
  secret(key: string): Promise<string | null>;
  accounts(): Promise<WealthfolioAccountLike[]>;
  /** Throws when the database cannot be read. */
  merchantRows(startInclusive: string, endExclusive: string): MerchantRow[];
  /** Wealthfolio's timezone setting; null when unset or unreadable. */
  timezone(): string | null;
}

export type ForecastClient = Pick<WealthfolioClient, 'getAddonSecret' | 'setAddonSecret' | 'getAccounts'>;

export function companionForecastReaders(client: Pick<ForecastClient, 'getAddonSecret' | 'getAccounts'>, dbPath: string): ForecastReaders {
  return {
    secret: (key) => client.getAddonSecret(ADDON_ID, key),
    accounts: () => client.getAccounts(),
    merchantRows: (start, endEx) => getNativeMerchantRows(dbPath, start, endEx, true),
    timezone: () => {
      try {
        return getNativeAuditSettings(dbPath).timezone;
      } catch {
        return null;
      }
    },
  };
}

class Unreachable extends Error {}

/** A JSON object secret: null when there is none, 'corrupt' when it is not an
 *  object; throws Unreachable when the read itself fails. */
async function readObject<T>(r: ForecastReaders, key: string): Promise<T | null | 'corrupt'> {
  let raw: string | null;
  try {
    raw = await r.secret(key);
  } catch {
    throw new Unreachable(key);
  }
  if (!raw) return null;
  try {
    const value: unknown = JSON.parse(raw);
    return typeof value === 'object' && value !== null && !Array.isArray(value) ? value as T : 'corrupt';
  } catch {
    return 'corrupt';
  }
}

/** The forecast, the reason there is none, or null when Wealthfolio could not be reached. */
export async function runCashForecast(r: ForecastReaders, now: Date): Promise<CashForecast | null> {
  try {
    return await gather(r, now);
  } catch (e) {
    if (e instanceof Unreachable) return null;
    throw e;
  }
}

async function gather(r: ForecastReaders, now: Date): Promise<CashForecast> {
  const mapping = await readObject<Record<string, string>>(r, 'account_mapping');
  if (mapping === 'corrupt') return failedForecast('mapping', now);
  const balances = await readObject<Record<string, { balance?: unknown; date?: unknown }>>(r, 'account_balances');
  if (balances === 'corrupt') return failedForecast('balances', now);
  // Names are cosmetic: an unreadable list falls back to Wealthfolio's own.
  const names = await readObject<Record<string, string>>(r, 'account_names');
  let accounts: WealthfolioAccountLike[];
  try {
    accounts = await r.accounts();
  } catch {
    return failedForecast('accounts', now);
  }
  const cash = cashToday({
    mapping: mapping ?? {}, balances: balances ?? {}, names: names === 'corrupt' ? {} : names ?? {}, accounts,
  });
  // Nothing to forecast: say why before reading anything else.
  if (cash.accounts.length === 0) return failedForecast(cash.missing.length > 0 ? 'noBalance' : 'noCash', now);

  let cubeRaw: string | null;
  try {
    cubeRaw = await r.secret(REPORT_CUBE_SECRET_KEY);
  } catch {
    throw new Unreachable(REPORT_CUBE_SECRET_KEY);
  }
  const cube = parseReportCube(cubeRaw);
  if (!cube) return failedForecast('history', now);
  let prefs: LoadedSubscriptionPrefs;
  try {
    prefs = await loadSubscriptionPrefs((key) => r.secret(key));
  } catch {
    throw new Unreachable('subscription_prefs');
  }
  // A corrupt document would drop the hand-added bills: say so instead.
  if (prefs.unreadable) return failedForecast('bills', now);

  const today = zonedDay(now, r.timezone());
  const roster = buildRoster({
    detected: cube.subscriptions ?? null,
    merchants: cube.merchants,
    links: cube.subscriptionLinks ?? [],
    prefs: prefs.prefs,
    today,
  });
  const months = historyMonths(cube, today.slice(0, 7));
  let merchantRows: MerchantRow[] = [];
  if (months.length > 0) {
    const { startInclusive, endExclusive } = historyWindow(months);
    try {
      merchantRows = r.merchantRows(startInclusive, endExclusive);
    } catch {
      return failedForecast('database', now);
    }
  }
  return buildCashForecast({ now, today, cash, roster, manual: prefs.prefs.manual, cube, months, merchantRows });
}

/**
 * Computes and writes `cash_forecast`. Writes nothing when Wealthfolio could
 * not be reached (the previous forecast stays); rejects when the write fails.
 * The sync's caller catches and logs either way — a publish never fails or
 * changes a sync.
 */
export async function publishCashForecast(
  client: ForecastClient,
  dbPath: string,
  now: Date,
  readers: ForecastReaders = companionForecastReaders(client, dbPath),
): Promise<boolean> {
  const forecast = await runCashForecast(readers, now);
  if (!forecast) return false;
  await client.setAddonSecret(ADDON_ID, CASH_FORECAST_SECRET_KEY, JSON.stringify(forecast));
  return true;
}
```

```ts
/**
 * shared/month-review.ts
 *
 * The month-end review (project 5 R1, spec B; ruling N4): the monthly
 * wrap-up's Full-detail section, from the report cube, the subscription
 * roster and the change log. Pure.
 *
 *  - Biggest changes: the three categories whose spending moved most against
 *    the month before (by size, either way).
 *  - Top merchants: the month's three biggest (the cube's merchant list).
 *  - Subscriptions: new ones — an entry whose whole charge history is known
 *    (the detector keeps the newest three) began in this month or the one
 *    before AND charged this month: a subscription needs two charges to be in
 *    the roster, so one that starts in a month is rarely known by its end;
 *    ones no longer charging ("cancelled?") — overdue since a date in or
 *    before this month; and price rises charged this month.
 *  - Net worth: the month-end change. Savings rate: (income − spent) ÷ income.
 *  - How many changes the change log shows (not background) for the month.
 *
 * Each line is left out when its data is missing or empty; a review with no
 * line at all is no section. Bank, merchant and category text is escaped in
 * the Telegram section and kept outside every entity.
 */
import type { ChangeLogRead } from './change-log.js';
import { changeLocalDay, isBackground, isChangeLogPartial } from './change-view.js';
import { monthlyIncomeTotals, monthlySpendTotals, type ReportCube } from './report-cube.js';
import { rosterMoney, rosterPrice, type Roster, type RosterEntry } from './subscription-roster.js';
import type { DetectedSubscription } from './subscriptions.js';
import { escapeMarkdown, moneyWhole, shortDate } from './telegram.js';

export const REVIEW_TOP = 3;
export const MONTH_REVIEW_HEADING = '*Month in review*';

export interface MonthReviewInput {
  /** The month reviewed, YYYY-MM. */
  month: string;
  cube: ReportCube | null;
  /** Built for the day the review is composed. */
  roster: Roster | null;
  changes: ChangeLogRead | null;
}

export interface MonthReview {
  month: string;
  changes: Array<{ category: string; deltaCents: number }> | null;
  merchants: Array<{ name: string; cents: number }> | null;
  newSubs: Array<{ entry: RosterEntry; since: string }> | null;
  gone: RosterEntry[] | null;
  rose: RosterEntry[] | null;
  netWorthDeltaCents: number | null;
  savingsRatePct: number | null;
  changeCount: number | null;
}

const orNull = <T>(list: T[]): T[] | null => (list.length > 0 ? list : null);
const monthBefore = (month: string): string => {
  const [y, m] = month.split('-').map(Number);
  return m === 1 ? `${y - 1}-12` : `${y}-${String(m - 1).padStart(2, '0')}`;
};

/** The first charge, known only when the newest three kept are all of them. */
function firstCharge(d: DetectedSubscription): string | null {
  const recent = d.recent ?? [];
  return recent.length > 0 && d.count <= recent.length ? recent[recent.length - 1].date : null;
}

export function buildMonthReview(input: MonthReviewInput): MonthReview {
  const { month, cube, roster, changes } = input;
  const previous = monthBefore(month);
  const mi = cube ? cube.months.indexOf(month) : -1;
  const pi = cube && mi >= 1 && cube.months[mi - 1] === previous ? mi - 1 : -1;

  let categoryChanges: MonthReview['changes'] = null;
  let merchants: MonthReview['merchants'] = null;
  let netWorthDeltaCents: number | null = null;
  let savingsRatePct: number | null = null;
  if (cube && mi >= 0) {
    const total = (m: number, ci: number) => cube.spend[m][ci].reduce((sum, v) => sum + v, 0);
    if (pi >= 0) {
      categoryChanges = orNull(cube.categories
        .map((category, ci) => ({ category, deltaCents: total(mi, ci) - total(pi, ci) }))
        .filter((c) => c.deltaCents !== 0)
        .sort((a, b) => Math.abs(b.deltaCents) - Math.abs(a.deltaCents) || a.category.localeCompare(b.category))
        .slice(0, REVIEW_TOP));
      const now = cube.netWorth[mi];
      const before = cube.netWorth[pi];
      if (now !== null && before !== null) netWorthDeltaCents = now - before;
    }
    merchants = orNull([...cube.merchants[mi]]
      .filter((m) => m.cents > 0)
      .sort((a, b) => b.cents - a.cents || a.name.localeCompare(b.name))
      .slice(0, REVIEW_TOP)
      .map(({ name, cents }) => ({ name, cents })));
    const income = monthlyIncomeTotals(cube)[mi];
    const spent = monthlySpendTotals(cube)[mi];
    if (income > 0) savingsRatePct = Math.round(((income - spent) / income) * 100);
  }

  let newSubs: MonthReview['newSubs'] = null;
  let gone: MonthReview['gone'] = null;
  let rose: MonthReview['rose'] = null;
  if (roster) {
    const entries = [...roster.subscriptions, ...roster.bills];
    if (cube?.subscriptions) {
      const detected = new Map(cube.subscriptions.map((d) => [d.name, d] as const));
      newSubs = orNull(entries.flatMap((entry) => {
        const d = detected.get(entry.source === 'detected' ? entry.key : entry.bankName ?? entry.displayName);
        const since = d ? firstCharge(d) : null;
        if (!d || !since || d.lastDate.slice(0, 7) !== month) return [];
        return since.slice(0, 7) === month || since.slice(0, 7) === previous ? [{ entry, since }] : [];
      }));
    }
    gone = orNull(entries.filter((e) => !!e.overdueSince && e.overdueSince.slice(0, 7) <= month));
    rose = orNull(entries.filter((e) => !!e.creep && e.creep.chargedOn.slice(0, 7) === month));
  }

  let changeCount: number | null = null;
  if (changes && !isChangeLogPartial(changes)) {
    const n = changes.entries.filter((e) => !isBackground(e) && changeLocalDay(e.at).slice(0, 7) === month).length;
    changeCount = n > 0 ? n : null;
  }

  return {
    month, changes: categoryChanges, merchants, newSubs, gone, rose, netWorthDeltaCents, savingsRatePct, changeCount,
  };
}

/** `+$120`, `-$80`; `$0` when it rounds away. */
function signed(cents: number): string {
  const text = moneyWhole(Math.abs(cents) / 100);
  return text === '$0' ? text : `${cents > 0 ? '+' : '-'}${text}`;
}

/** The review as the monthly report's section (legacy Markdown), or null
 *  when it has no line. */
export function formatMonthReview(r: MonthReview): string | null {
  const lines: string[] = [];
  if (r.changes) {
    lines.push(`Biggest changes: ${r.changes.map((c) => `${escapeMarkdown(c.category)} ${signed(c.deltaCents)}`).join(' · ')}`);
  }
  if (r.merchants) {
    lines.push(`Top merchants: ${r.merchants.map((m) => `${escapeMarkdown(m.name)} ${moneyWhole(m.cents / 100)}`).join(' · ')}`);
  }
  if (r.newSubs) {
    lines.push(`New: ${r.newSubs.map(({ entry, since }) => `${escapeMarkdown(entry.displayName)} ${rosterPrice(entry)} (since ${shortDate(since)})`).join(' · ')}`);
  }
  if (r.gone) lines.push(`No longer charging (cancelled?): ${r.gone.map((e) => escapeMarkdown(e.displayName)).join(' · ')}`);
  if (r.rose) {
    lines.push(`Rose in price: ${r.rose.map((e) => `${escapeMarkdown(e.displayName)} ${rosterMoney(e.creep!.fromCents)} → ${rosterMoney(e.creep!.toCents)}`).join(' · ')}`);
  }
  if (r.netWorthDeltaCents !== null) lines.push(`Net worth: ${signed(r.netWorthDeltaCents)} over the month`);
  if (r.savingsRatePct !== null) lines.push(`Savings rate: ${r.savingsRatePct}%`);
  if (r.changeCount !== null) {
    const n = r.changeCount;
    lines.push(`${n} ${n === 1 ? 'change was' : 'changes were'} made to your books (see /changes).`);
  }
  return lines.length > 0 ? `${MONTH_REVIEW_HEADING}\n${lines.join('\n')}` : null;
}
```

```ts
/**
 * shared/reports-seen.ts
 *
 * The Reports tab's unread state (project 5 R1, spec C; ruling N5): which
 * report editions the person has seen, kept in the `reports_seen` add-on
 * secret — `{ daily?, weekly?, monthly? }`, the newest `generatedAt` seen per
 * kind — so it is shared across their devices. The add-on is its only writer.
 *
 * What counts: SENT editions only (the archive). The live edition is
 * recomposed after every sync and is never "new". An edition is unread when it
 * was generated after its kind's seen time; a kind the document has no time
 * for yet counts every sent edition. With no document (the first run) or one
 * nothing can read, everything counts as seen and the newest editions become
 * the baseline, so later ones count as new.
 */
import { REPORT_KINDS, type ReportEdition, type ReportKind, type ReportStore } from './reports-archive.js';

export const REPORTS_SEEN_SECRET_KEY = 'reports_seen';

export type ReportsSeen = Partial<Record<ReportKind, string>>;

export type ReportsSeenRead =
  | { kind: 'ok'; seen: ReportsSeen }
  | { kind: 'absent' }
  | { kind: 'corrupt' };

export const NO_UNREAD: Readonly<Record<ReportKind, number>> = { daily: 0, weekly: 0, monthly: 0 };

const time = (iso: unknown): number | null => {
  if (typeof iso !== 'string') return null;
  const t = Date.parse(iso);
  return Number.isFinite(t) ? t : null;
};

/** Absent for nothing stored; corrupt for anything that is not an object
 *  whose known kinds are readable times. Unknown keys are ignored. */
export function parseReportsSeen(raw: string | null | undefined): ReportsSeenRead {
  if (raw === null || raw === undefined || raw === '') return { kind: 'absent' };
  let v: unknown;
  try {
    v = JSON.parse(raw);
  } catch {
    return { kind: 'corrupt' };
  }
  if (!v || typeof v !== 'object' || Array.isArray(v)) return { kind: 'corrupt' };
  const seen: ReportsSeen = {};
  for (const kind of REPORT_KINDS) {
    const value = (v as Record<string, unknown>)[kind];
    if (value === undefined) continue;
    if (time(value) === null) return { kind: 'corrupt' };
    seen[kind] = value as string;
  }
  return { kind: 'ok', seen };
}

/** The newest sent edition's `generatedAt`, or null when none can be read. */
export function newestEdition(store: ReportStore): string | null {
  let newest: string | null = null;
  let newestTime = Number.NEGATIVE_INFINITY;
  for (const e of store.archive) {
    const t = time(e.generatedAt);
    if (t !== null && t > newestTime) {
      newest = e.generatedAt;
      newestTime = t;
    }
  }
  return newest;
}

/** Generated after `seenAt`; every edition when the kind has no time yet.
 *  An edition whose time cannot be read is never "new". */
export function isUnread(edition: ReportEdition, seenAt: string | undefined): boolean {
  const t = time(edition.generatedAt);
  if (t === null) return false;
  if (seenAt === undefined) return true;
  const s = time(seenAt);
  return s !== null && t > s;
}

export function unreadCount(store: ReportStore, seenAt: string | undefined): number {
  return store.archive.filter((e) => isUnread(e, seenAt)).length;
}

/** Per kind; all zero when nothing is known to be seen (null). */
export function unreadCounts(stores: Partial<Record<ReportKind, ReportStore>>, seen: ReportsSeen | null): Record<ReportKind, number> {
  const counts = { ...NO_UNREAD };
  if (seen === null) return counts;
  for (const kind of REPORT_KINDS) {
    const store = stores[kind];
    if (store) counts[kind] = unreadCount(store, seen[kind]);
  }
  return counts;
}

/** The first run's (or a rewrite's) document: each kind's newest edition, so
 *  everything there now counts as seen. A kind with none is left out. */
export function baselineSeen(stores: Partial<Record<ReportKind, ReportStore>>): ReportsSeen {
  const seen: ReportsSeen = {};
  for (const kind of REPORT_KINDS) {
    const store = stores[kind];
    const newest = store ? newestEdition(store) : null;
    if (newest) seen[kind] = newest;
  }
  return seen;
}

/** The document after opening `kind`'s sub-tab, or null when nothing would
 *  change — so a second visit writes nothing. */
export function markSeen(seen: ReportsSeen, kind: ReportKind, store: ReportStore): ReportsSeen | null {
  const newest = newestEdition(store);
  if (newest === null) return null;
  const current = time(seen[kind]);
  if (current !== null && time(newest)! <= current) return null;
  return { ...seen, [kind]: newest };
}

/** "Reports, 2 unread" — a tab's accessible name while it has unread editions. */
export function unreadLabel(label: string, count: number): string {
  return `${label}, ${count} unread`;
}
```

```ts
import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import { REPORT_KINDS, type ReportKind, type ReportStore } from '../../shared/reports-archive';
import {
  baselineSeen, markSeen, unreadCounts, type ReportsSeen, type ReportsSeenRead,
} from '../../shared/reports-seen';

/** What the inbox reads and writes; the seen pair is optional-called, so an
 *  older store simply counts nothing. */
export interface ReportsInboxStore {
  getReports(kind: ReportKind): Promise<ReportStore>;
  getReportsSeen?(): Promise<ReportsSeenRead>;
  setReportsSeen?(seen: ReportsSeen): Promise<void>;
}

export interface ReportsInbox {
  /** Unread sent editions per kind — all zero until read, and whenever what
   *  was seen cannot be known. */
  counts: Record<ReportKind, number>;
  total: number;
  /** What was seen, as last read or written; null until known. */
  seen: ReportsSeen | null;
  /** Re-read the seen state and the three archives. */
  refresh(): void;
  /** A kind's sub-tab opened on `data`: marks it seen, one best-effort write. */
  opened(kind: ReportKind, data: ReportStore): void;
}

/**
 * The Reports tab's unread state (project 5 R1, spec C; ruling N5), held by
 * the page so the tab bar's count and the sub-tabs agree.
 *
 * First run (no `reports_seen`) or a value nothing can read: everything counts
 * as seen and each kind's newest edition is written as the baseline, once per
 * page, best-effort. A host read that fails counts nothing and writes nothing.
 * Marking seen writes one document at a time (a queue), so two sub-tabs
 * opened quickly cannot overwrite each other; a failed write leaves the count
 * as it was and never throws; nothing is set after unmount.
 */
export function useReportsInbox(store: ReportsInboxStore): ReportsInbox {
  const [seen, setSeen] = useState<ReportsSeen | null>(null);
  const [stores, setStores] = useState<Partial<Record<ReportKind, ReportStore>>>({});
  const seenRef = useRef<ReportsSeen | null>(null);
  const mounted = useRef(true);
  const baselineTried = useRef(false);
  const queue = useRef<Promise<unknown>>(Promise.resolve());
  useEffect(() => {
    mounted.current = true;
    return () => { mounted.current = false; };
  }, []);

  const refresh = useCallback(() => {
    if (!store.getReportsSeen) return;
    Promise.all([store.getReportsSeen(), Promise.all(REPORT_KINDS.map((k) => store.getReports(k)))])
      .then(([read, list]) => {
        if (!mounted.current) return;
        const byKind: Partial<Record<ReportKind, ReportStore>> = {};
        REPORT_KINDS.forEach((k, i) => { byKind[k] = list[i]; });
        setStores(byKind);
        if (read.kind === 'ok') {
          seenRef.current = read.seen;
          setSeen(read.seen);
          return;
        }
        const baseline = baselineSeen(byKind);
        seenRef.current = baseline;
        setSeen(baseline);
        if (baselineTried.current) return;
        baselineTried.current = true;
        store.setReportsSeen?.(baseline)?.catch(() => {});
      })
      .catch(() => {});
  }, [store]);

  useEffect(() => { refresh(); }, [refresh]);

  const opened = useCallback((kind: ReportKind, data: ReportStore) => {
    if (!store.setReportsSeen) return;
    const run = async () => {
      const current = seenRef.current;
      if (!current) return;
      const next = markSeen(current, kind, data);
      if (!next) return;
      try {
        await store.setReportsSeen!(next);
      } catch {
        return;
      }
      seenRef.current = next;
      if (!mounted.current) return;
      setSeen(next);
      setStores((prev) => ({ ...prev, [kind]: data }));
    };
    queue.current = queue.current.then(run, run);
  }, [store]);

  const counts = useMemo(() => unreadCounts(stores, seen), [stores, seen]);
  const total = counts.daily + counts.weekly + counts.monthly;
  return useMemo(() => ({ counts, total, seen, refresh, opened }), [counts, total, seen, refresh, opened]);
}
```
