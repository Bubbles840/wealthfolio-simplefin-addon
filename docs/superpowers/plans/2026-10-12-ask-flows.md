# Question-and-answer Telegram flows (R1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Telegram bot a shared ask-and-answer engine, and make bare `/pool`, `/newrule` and `/afford` ask for what they need one question at a time, while every one-line form keeps working.

**Architecture:** A pure step machine in `shared/ask-flow.ts` renders questions and interprets answers. A companion-side session holder (`companion/src/ask-session.ts`) keeps the ONE open question in memory, routes the chat's next plain message and `cz:ak:` button taps into the engine, and expires it after 15 minutes. Flow definitions live in `companion/src/ask-flows.ts` (they need the database); `companion/src/index.ts` registers them and wires the listener's new optional `onText` dependency.

**Tech Stack:** TypeScript, vitest (root project: jsdom, `src/` + `shared/`; companion project: node, `companion/src/`), Telegram Bot API (legacy `Markdown` parse mode).

**Spec:** `docs/superpowers/specs/2026-10-12-subscriptions-and-ask-flows-design.md` — Part A. Part B (subscriptions) gets its own plan after this one ships.

## Global Constraints

- **One-line forms are unchanged.** `/pool 16000 Dec 12`, `/pool off`, `/newrule trader joes = groceries`, `/afford 20 shopping` behave exactly as today; only the BARE command (empty args) changes.
- **Telegram replies use legacy `Markdown`.** Any user- or bank-supplied text placed in a message goes through `escapeMarkdown` (`shared/telegram.ts`). The engine never escapes; flow definitions do.
- **`callback_data` ≤ 64 bytes.** Engine buttons are `cz:ak:<seq>:<step>:<action>`; flow-start buttons are `cz:ak:go:<flowId>[:<arg>]`.
- **Routing order:** `cz:ak:` taps are offered to the ask sessions BEFORE the categorize controller, which treats unknown `cz:` data as an expired menu.
- **The bot honours one configured chat**, so there is ONE open question at a time (a single slot, not a per-chat map).
- **Expiry:** 15 minutes after the last answer. An expired flow's command is remembered for 1 hour for the "send /pool again" reply.
- **New listener deps are OPTIONAL**; absent means today's behaviour (plain text is silently dropped).
- **Tests use a fixed `now`** — never the real date.
- **Gates before calling a task done:** the touched project's tests; before the final task: `npm test`, `npm --prefix companion test`, `npm run type-check`, `npm --prefix companion run build`.
- **No version bump, tag or release.** Nick asks for releases himself; CHANGELOG goes under `[Unreleased]`.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **A tap on an older question's button after answering by text** → "That question has moved on.", nothing changes. Pinned in Task 3.
- **A `/command` sent while a question is open** → one "Cancelled your earlier question." line, then the command runs normally. Pinned in Task 4.
- **Answering after the 15-minute expiry** → "That question expired — send /pool again." (names the right command), not silence. Pinned in Task 3.
- **Typing a choice instead of tapping it** ("yes, clear", "Yes clear") → accepted when it matches an option's label. Pinned in Task 2.
- **Category names with Markdown characters** (`Food_Drink`, `Kids*`) in prompts and button echoes → escaped, so Telegram does not refuse the message. Pinned in Task 6.

/** Cents from what a person types for money: `20`, `9.99`, `$16,000.50`.
 *  Null for anything else — including zero, negatives and a third decimal —
 *  so one caller-chosen hint covers every miss. Shared by the one-line
 *  commands and the question flows so the two can never read money
 *  differently. */
export function parseAmountCents(text: string): number | null {
  const raw = (text ?? '').trim().replace(/[$,]/g, '');
  if (!/^\d+(\.\d{1,2})?$/.test(raw)) return null;
  const cents = Math.round(parseFloat(raw) * 100);
  return cents > 0 ? cents : null;
}

/** A date as a person types it: `2026-12-12`, `Dec 12`, `december 12th`,
 *  `today`, `tomorrow`. A month-day is THIS year's — possibly already past;
 *  what a past date means is the CALLER's policy (`/pool` refuses a past ISO
 *  date but rolls a month-day forward; a subscription rolls everything). */
export function parseDateInput(
  text: string,
  now: Date,
): { iso: string; form: 'iso' | 'month-day' | 'relative' } | null {
  const t = (text ?? '').trim().toLowerCase();
  if (t === 'today' || t === 'tomorrow') {
    const d = new Date(Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate() + (t === 'tomorrow' ? 1 : 0)));
    return { iso: d.toISOString().slice(0, 10), form: 'relative' };
  }
  if (/^\d{4}-\d{2}-\d{2}$/.test(t)) {
    const [y, m, d] = t.split('-').map((n) => parseInt(n, 10));
    return poolDateString(y, m - 1, d) === t ? { iso: t, form: 'iso' } : null;
  }
  const md = t.match(/^([a-z]{3,9})\.?\s+(\d{1,2})(?:st|nd|rd|th)?,?$/);
  if (!md) return null;
  const monthIndex = POOL_MONTH_PREFIXES.indexOf(md[1].slice(0, 3));
  if (monthIndex === -1) return null;
  const iso = poolDateString(now.getUTCFullYear(), monthIndex, parseInt(md[2], 10));
  return iso === null ? null : { iso, form: 'month-day' };
}

/** `iso` when it is today or later; otherwise the same month and day next
 *  year (Feb 29 lands on Feb 28 when next year has none). */
export function nextOccurrence(iso: string, today: string): string {
  if (iso >= today) return iso;
  const [y, m, d] = iso.split('-').map((n) => parseInt(n, 10));
  return poolDateString(y + 1, m - 1, d) ?? poolDateString(y + 1, m - 1, d - 1)!;
}
```

/**
 * shared/ask-flow.ts
 *
 * The bot's question-and-answer engine: a flow is a list of steps, each a
 * typed answer or a choice, optionally ending on a summary with Save. Pure —
 * the companion owns the open question, the clock and the transport
 * (companion/src/ask-session.ts); this file only renders a step and decides
 * what an answer means.
 *
 * It never escapes text: prompts, hints, option labels and summaries arrive
 * from the flow definitions, which know which parts are user-supplied.
 */
import type { InlineKeyboard } from './telegram.js';

export const ASK_CALLBACK_PREFIX = 'cz:ak:';
const START_PREFIX = `${ASK_CALLBACK_PREFIX}go:`;

export const ASK_BACK = '‹ Back';
export const ASK_CANCEL = '✖ Cancel';
export const ASK_SAVE = '✅ Save';

const SUMMARY_HINT = 'Tap ✅ Save, or ‹ Back to change something.';
const CHOICE_HINT = 'Tap one of the buttons.';

export type Answers = Record<string, unknown>;
export type StepResult = { ok: true; value: unknown } | { ok: false; hint: string };
export interface AskOption { label: string; value: unknown }

export type AskStep =
  | {
    id: string;
    kind: 'text';
    prompt: (a: Answers) => string;
    parse: (input: string, a: Answers) => StepResult;
    /** Buttons offered beside typing, e.g. the most-used categories. */
    quick?: (a: Answers) => AskOption[];
  }
  | { id: string; kind: 'choice'; prompt: (a: Answers) => string; options: (a: Answers) => AskOption[] };

export interface AskFlow {
  id: string;
  /** The command that starts it, without the slash — named by the expiry reply. */
  command: string;
  title: string;
  steps: AskStep[];
  /** Present → the flow ends on this summary with ✅ Save. Absent → the last
   *  answer finishes it. */
  summary?: (a: Answers) => string;
}

/** `step === flow.steps.length` is the summary screen. */
export interface AskState { seq: string; step: number; answers: Answers }
export interface AskScreen { text: string; keyboard: InlineKeyboard }

export type AskOutcome =
  | { kind: 'screen'; state: AskState; screen: AskScreen; echo?: string }
  | { kind: 'retry'; state: AskState; screen: AskScreen }
  | { kind: 'done'; answers: Answers; echo?: string }
  | { kind: 'cancel' }
  | { kind: 'stale' };

type Button = { text: string; callback_data: string };

const data = (state: AskState, action: string) => `${ASK_CALLBACK_PREFIX}${state.seq}:${state.step}:${action}`;

const pairs = (list: Button[]): Button[][] => {
  const rows: Button[][] = [];
  for (let i = 0; i < list.length; i += 2) rows.push(list.slice(i, i + 2));
  return rows;
};

const normalize = (s: string) => s.toLowerCase().replace(/[^a-z0-9]+/g, ' ').trim();

export function renderAsk(flow: AskFlow, state: AskState, hint?: string): AskScreen {
  const n = flow.steps.length;
  const hintLine = hint ? [`⚠️ ${hint}`] : [];
  if (state.step >= n) {
    return {
      text: [`*${flow.title}*`, ...hintLine, flow.summary ? flow.summary(state.answers) : ''].join('\n'),
      keyboard: {
        inline_keyboard: [
          [{ text: ASK_SAVE, callback_data: data(state, 's') }],
          [{ text: ASK_BACK, callback_data: data(state, 'b') }, { text: ASK_CANCEL, callback_data: data(state, 'x') }],
        ],
      },
    };
  }
  const step = flow.steps[state.step];
  const head = n > 1 ? `*${flow.title} · ${state.step + 1} of ${n}*` : `*${flow.title}*`;
  const picks = step.kind === 'choice'
    ? step.options(state.answers).map((o, i) => ({ text: o.label, callback_data: data(state, `c${i}`) }))
    : (step.quick?.(state.answers) ?? []).map((o, i) => ({ text: o.label, callback_data: data(state, `q${i}`) }));
  return {
    text: [head, ...hintLine, step.prompt(state.answers)].join('\n'),
    keyboard: {
      inline_keyboard: [
        ...pairs(picks),
        [{ text: ASK_BACK, callback_data: data(state, 'b') }, { text: ASK_CANCEL, callback_data: data(state, 'x') }],
      ],
    },
  };
}

export function startAsk(flow: AskFlow, seq: string): { state: AskState; screen: AskScreen } {
  const state: AskState = { seq, step: 0, answers: {} };
  return { state, screen: renderAsk(flow, state) };
}

function advance(flow: AskFlow, state: AskState, value: unknown, echo?: string): AskOutcome {
  const answers = { ...state.answers, [flow.steps[state.step].id]: value };
  const next = state.step + 1;
  if (next >= flow.steps.length && !flow.summary) return { kind: 'done', answers, ...(echo ? { echo } : {}) };
  const nextState: AskState = { seq: state.seq, step: next, answers };
  return { kind: 'screen', state: nextState, screen: renderAsk(flow, nextState), ...(echo ? { echo } : {}) };
}

const retry = (flow: AskFlow, state: AskState, hint: string): AskOutcome =>
  ({ kind: 'retry', state, screen: renderAsk(flow, state, hint) });

export function answerText(flow: AskFlow, state: AskState, text: string): AskOutcome {
  if (state.step >= flow.steps.length) return retry(flow, state, SUMMARY_HINT);
  const step = flow.steps[state.step];
  const input = text.trim();
  if (step.kind === 'choice') {
    const wanted = normalize(input);
    const option = step.options(state.answers).find((o) => normalize(o.label) === wanted);
    return option ? advance(flow, state, option.value) : retry(flow, state, CHOICE_HINT);
  }
  const result = step.parse(input, state.answers);
  return result.ok ? advance(flow, state, result.value) : retry(flow, state, result.hint);
}

const ANSWER = /^cz:ak:([0-9a-z]+):(\d+):(x|b|s|c\d+|q\d+)$/;

export function answerButton(flow: AskFlow, state: AskState, raw: string): AskOutcome {
  const m = raw.match(ANSWER);
  if (!m || m[1] !== state.seq || Number(m[2]) !== state.step) return { kind: 'stale' };
  const action = m[3];
  const atSummary = state.step >= flow.steps.length;
  if (action === 'x') return { kind: 'cancel' };
  if (action === 'b') {
    if (state.step === 0) return { kind: 'cancel' };
    const back: AskState = { ...state, step: state.step - 1 };
    return { kind: 'screen', state: back, screen: renderAsk(flow, back) };
  }
  if (action === 's') return atSummary ? { kind: 'done', answers: state.answers, echo: ASK_SAVE } : { kind: 'stale' };
  if (atSummary) return { kind: 'stale' };
  const step = flow.steps[state.step];
  const index = Number(action.slice(1));
  const list = action[0] === 'c'
    ? (step.kind === 'choice' ? step.options(state.answers) : [])
    : (step.kind === 'text' ? step.quick?.(state.answers) ?? [] : []);
  const option = list[index];
  return option ? advance(flow, state, option.value, option.label) : { kind: 'stale' };
}

export function askStartData(flowId: string, arg?: string): string {
  return `${START_PREFIX}${flowId}${arg !== undefined ? `:${arg}` : ''}`;
}

export function parseAskStart(raw: string): { flowId: string; arg?: string } | null {
  if (!raw.startsWith(START_PREFIX)) return null;
  const [flowId, ...rest] = raw.slice(START_PREFIX.length).split(':');
  if (!flowId) return null;
  return rest.length > 0 ? { flowId, arg: rest.join(':') } : { flowId };
}

/**
 * companion/src/ask-session.ts
 *
 * The bot's ONE open question. The listener honours a single configured chat,
 * so this is a slot, not a per-chat map. It lives in memory on purpose: a
 * restart loses it, and the next answer is told so ("I'm not waiting for an
 * answer right now") rather than ignored.
 *
 * Text answers arrive through the listener's `onText`; buttons through
 * `onMenuCallback`, which must offer `cz:ak:` data HERE before the categorize
 * controller treats it as an expired menu.
 */
import {
  ASK_CALLBACK_PREFIX, answerButton, answerText, parseAskStart, startAsk,
  type AskFlow, type AskOutcome, type AskState, type Answers,
} from '../../shared/ask-flow.js';
import { escapeMarkdown, type InlineKeyboard } from '../../shared/telegram.js';

export type AskSend = (text: string, keyboard?: InlineKeyboard) => Promise<void>;
export interface AskUi {
  edit(text: string, keyboard?: InlineKeyboard): Promise<void>;
  answer(text?: string): Promise<void>;
  send: AskSend;
}
export interface AskRun { flow: AskFlow; onDone: (answers: Answers, send: AskSend) => Promise<void> }
export type AskFactory = (arg: string | undefined, send: AskSend) => Promise<AskRun | null>;

export const CANCELLED_EARLIER = 'Cancelled your earlier question.';
export const NOT_WAITING = "I'm not waiting for an answer right now — /help lists what I can do.";
export const ASK_MOVED_ON = 'That question has moved on.';
const QUESTION_GONE = 'That question expired.';
const UNKNOWN_FLOW = 'That button is no longer available.';
const DONE_FAILED = 'Something went wrong finishing that — check the companion logs.';

export function expiredReply(command: string): string {
  return `That question expired — send /${command} again.`;
}

export interface AskSessions {
  register(flowId: string, factory: AskFactory): void;
  start(flowId: string, send: AskSend, arg?: string): Promise<void>;
  cancelForCommand(): boolean;
  onText(text: string, send: AskSend): Promise<void>;
  handles(data: string): boolean;
  onCallback(cb: { data: string }, ui: AskUi): Promise<void>;
}

interface Open { run: AskRun; state: AskState; lastAt: number; lastText: string }

export function createAskSessions(opts: {
  now?: () => number;
  ttlMs?: number;
  expiredMemoryMs?: number;
  /** First sequence number. Defaults to the process start time, so a button
   *  minted before a restart can never match a flow started after it. */
  seqBase?: number;
  log?: (m: string) => void;
} = {}): AskSessions {
  const now = opts.now ?? Date.now;
  const ttl = opts.ttlMs ?? 15 * 60_000;
  const expiredMemory = opts.expiredMemoryMs ?? 60 * 60_000;
  const log = opts.log ?? (() => {});
  let counter = opts.seqBase ?? Date.now();
  const factories = new Map<string, AskFactory>();
  let open: Open | null = null;
  let expired: { command: string; at: number } | null = null;

  const current = (): Open | null => {
    if (open && now() - open.lastAt > ttl) {
      expired = { command: open.run.flow.command, at: now() };
      open = null;
    }
    return open;
  };

  const show = async (o: Open, outcome: Extract<AskOutcome, { kind: 'screen' | 'retry' }>, send: AskSend, prefix = '') => {
    o.state = outcome.state;
    o.lastAt = now();
    o.lastText = outcome.screen.text;
    await send(`${prefix}${outcome.screen.text}`, outcome.screen.keyboard);
  };

  const finish = async (run: AskRun, answers: Answers, send: AskSend) => {
    try {
      await run.onDone(answers, send);
    } catch (err) {
      log(`Ask flow ${run.flow.id}: finishing failed: ${err instanceof Error ? err.message : String(err)}`);
      await send(DONE_FAILED);
    }
  };

  const start = async (flowId: string, send: AskSend, arg?: string) => {
    const factory = factories.get(flowId);
    if (!factory) {
      log(`Ask flow ${flowId}: no such flow`);
      await send(UNKNOWN_FLOW);
      return;
    }
    const replaced = current() !== null;
    open = null;
    const run = await factory(arg, send);
    if (!run) return;
    const seq = (counter++).toString(36);
    const { state, screen } = startAsk(run.flow, seq);
    const o: Open = { run, state, lastAt: now(), lastText: screen.text };
    open = o;
    expired = null;
    await send(`${replaced ? `${CANCELLED_EARLIER}\n\n` : ''}${screen.text}`, screen.keyboard);
  };

  return {
    register(flowId, factory) {
      factories.set(flowId, factory);
    },

    start,

    cancelForCommand() {
      const had = current() !== null;
      open = null;
      return had;
    },

    async onText(text, send) {
      const o = current();
      if (!o) {
        if (expired && now() - expired.at <= expiredMemory) {
          const command = expired.command;
          expired = null;
          await send(expiredReply(command));
        } else {
          expired = null;
          await send(NOT_WAITING);
        }
        return;
      }
      const outcome = answerText(o.run.flow, o.state, text);
      if (outcome.kind === 'screen' || outcome.kind === 'retry') {
        await show(o, outcome, send);
      } else if (outcome.kind === 'done') {
        open = null;
        await finish(o.run, outcome.answers, send);
      }
    },

    handles(data) {
      return data.startsWith(ASK_CALLBACK_PREFIX);
    },

    async onCallback(cb, ui) {
      const go = parseAskStart(cb.data);
      if (go) {
        await ui.answer();
        await start(go.flowId, ui.send, go.arg);
        return;
      }
      const o = current();
      if (!o) {
        await ui.answer(QUESTION_GONE);
        return;
      }
      const outcome = answerButton(o.run.flow, o.state, cb.data);
      if (outcome.kind === 'stale') {
        await ui.answer(ASK_MOVED_ON);
        return;
      }
      await ui.answer();
      if (outcome.kind === 'cancel') {
        open = null;
        await ui.edit(`${o.lastText}\n→ Cancelled.`);
        return;
      }
      // The tapped question keeps its text and loses its buttons, so the chat
      // reads as a record of what was answered.
      await ui.edit(outcome.kind !== 'retry' && outcome.echo ? `${o.lastText}\n→ ${escapeMarkdown(outcome.echo)}` : o.lastText);
      if (outcome.kind === 'done') {
        open = null;
        await finish(o.run, outcome.answers, ui.send);
        return;
      }
      await show(o, outcome, ui.send);
    },
  };
}
```

/**
 * companion/src/ask-flows.ts
 *
 * The bot's question flows. Pure builders — the data they need (categories,
 * counts, budget rows) is passed in — so each can be driven through the shared
 * engine in a test without a database. index.ts registers them and owns what
 * happens on Save.
 *
 * The engine never escapes; anything user- or bank-supplied that a prompt or
 * summary prints goes through `escapeMarkdown` here.
 */
import type { AskFlow } from '../../shared/ask-flow.js';
import { formatDollars, shortDate } from '../../shared/telegram.js';
import { nextOccurrence, parseAmountCents, parseDateInput } from '../../shared/telegram-commands.js';

const AMOUNT_HINT = "Couldn't read that as an amount — try 16000 or $16,000.";
const DATE_HINT = "Couldn't read that date — try Dec 12 or 2026-12-12.";

export function buildPoolSetFlow(now: Date): AskFlow {
  const today = now.toISOString().slice(0, 10);
  return {
    id: 'pool-set',
    command: 'pool',
    title: 'Semester pool',
    steps: [
      {
        id: 'amount',
        kind: 'text',
        prompt: () => 'How much is the pool? (e.g. 16000)',
        parse: (input) => {
          const cents = parseAmountCents(input);
          return cents === null ? { ok: false, hint: AMOUNT_HINT } : { ok: true, value: cents };
        },
      },
      {
        id: 'until',
        kind: 'text',
        prompt: (a) => `${formatDollars((a.amount as number) / 100, 0)} has to last until when? (e.g. Dec 12)`,
        parse: (input) => {
          const date = parseDateInput(input, now);
          if (date === null) return { ok: false, hint: DATE_HINT };
          if (date.form === 'iso' && date.iso < today) return { ok: false, hint: 'That date has passed — pick one ahead of today.' };
          return { ok: true, value: date.form === 'month-day' ? nextOccurrence(date.iso, today) : date.iso };
        },
      },
    ],
    summary: (a) => `*${formatDollars((a.amount as number) / 100, 0)}* from today until *${shortDate(a.until as string)}*.`,
  };
}

export function buildPoolClearFlow(): AskFlow {
  return {
    id: 'pool-clear',
    command: 'pool',
    title: 'Clear the pool',
    steps: [{
      id: 'confirm',
      kind: 'choice',
      prompt: () => 'Clear the pool? Reports go back to budgets only.',
      options: () => [{ label: 'Yes, clear', value: true }],
    }],
  };
}

import { categoryDisplayName } from '../../shared/categorize-menu.js';
import { escapeMarkdown } from '../../shared/telegram.js';
import { formatCategoryQueryMiss, NEWRULE_CATEGORY_LIST_HINT, resolveCategoryQuery } from '../../shared/telegram-commands.js';
import type { NativeSpendingCategory } from './sqlite-native.js';

/** The spending categories filed most often in `rows`, most-used first —
 *  `/newrule`'s quick picks. Other taxonomies and deleted categories drop. */
export function mostUsedCategories(
  rows: ReadonlyArray<{ assignments: ReadonlyArray<{ taxonomyId: string; categoryId: string }> }>,
  categories: NativeSpendingCategory[],
  limit = 6,
): NativeSpendingCategory[] {
  const counts = new Map<string, number>();
  for (const row of rows) {
    for (const a of row.assignments) {
      if (a.taxonomyId === 'spending_categories') counts.set(a.categoryId, (counts.get(a.categoryId) ?? 0) + 1);
    }
  }
  const byId = new Map(categories.map((c) => [c.id, c]));
  return [...counts.entries()]
    .sort((a, b) => b[1] - a[1])
    .map(([id]) => byId.get(id))
    .filter((c): c is NativeSpendingCategory => c !== undefined)
    .slice(0, limit);
}

export function buildNewRuleFlow(input: {
  categories: NativeSpendingCategory[];
  mostUsed: NativeSpendingCategory[];
  countMatches: (pattern: string) => number;
}): AskFlow {
  return {
    id: 'newrule',
    command: 'newrule',
    title: 'New rule',
    steps: [
      {
        id: 'pattern',
        kind: 'text',
        prompt: () => "Which words from the bank's description should the rule match? (e.g. trader joes)",
        parse: (text) => (/[a-z]/i.test(text)
          ? { ok: true, value: text.trim() }
          : { ok: false, hint: "Type a few words from the bank's description, e.g. trader joes." }),
      },
      {
        id: 'category',
        kind: 'text',
        prompt: (a) => {
          const pattern = a.pattern as string;
          const n = input.countMatches(pattern);
          const quoted = `"${escapeMarkdown(pattern)}"`;
          const head = n === 0
            ? `No charges in the past year match ${quoted} yet — the rule will still file future ones.`
            : `${n} ${n === 1 ? 'charge' : 'charges'} in the past year match ${quoted}.`;
          return `${head}\nWhich category should they go to? Type a name or tap one.`;
        },
        parse: (text) => {
          const result = resolveCategoryQuery(input.categories, text);
          if (result.kind === 'one') return { ok: true, value: result.category.id };
          return { ok: false, hint: formatCategoryQueryMiss(result, text, NEWRULE_CATEGORY_LIST_HINT) ?? 'No category by that name.' };
        },
        quick: () => input.mostUsed.map((c) => ({ label: categoryDisplayName(c), value: c.id })),
      },
    ],
  };
